# Utility Scripts

Script                                | Purpose
--------------------------------------|-----------
checkDirty.py                         | Check for uncommitted changes or being behind in all subdirectories
checkout.py \<match> \<branch>        | Check out a branch in all matching subdirectories
conanRemove.py \<match> \<version>    | Remove a version in all matching subdirectories
setAuthor \<match> \<author> \<email> | Set git author and email in all matching subdirectories
